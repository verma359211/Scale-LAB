# Experiment reports

These documents preserve the measured experiments and the reasoning behind ScaleLab's topology. They are historical reports, not current deployment instructions.

Raw k6/Prometheus/container exports are deliberately excluded from the current Git tree. The original operator's captures remain locally in the ignored `results/` directory. References to dated result filenames in a report describe that original run; a fresh clone will not contain those captures. Generate new local results with the current runners rather than treating old settings or numbers as a production guarantee.

See the root README for supported setup commands and `docs/REPOSITORY_HYGIENE.md` for artifact/credential handling. No old temporary benchmark-exposure Service should be recreated from an experiment narrative.
